3. Create `src/components/ChargesPanel/TipControl.tsx` (per D-09, D-10, D-13):

   - Imports: `useState` from react, `Button` from `@/components/ui/button`, `Input` from `@/components/ui/input`, `useBillStore` from `@/store/useBillStore`
   - Read from store: `const tip = useBillStore((s) => s.tip)` and `const setTip = useBillStore((s) => s.setTip)`
   - Local state: `const [isCustom, setIsCustom] = useState(false)`, `const [customValue, setCustomValue] = useState('')`, `const [isInvalid, setIsInvalid] = useState(false)`
   - Preset values: `const PRESETS = [15, 18, 20] as const`
   - `handlePresetClick(percent: number)`: call `setIsCustom(false)`, `setCustomValue('')`, `setIsInvalid(false)`, `setTip({ value: percent, mode: 'percent' })`
   - `handleCustomClick()`: call `setIsCustom(true)`, `setTip({ value: 0, mode: 'percent' })`
   - `handleCustomChange(e: React.ChangeEvent<HTMLInputElement>)`:
     - `const val = e.target.value; setCustomValue(val);`
     - If `val === ''`: `setIsInvalid(false); setTip({ value: 0 }); return;`
     - `const parsed = parseFloat(val)`
     - If `isNaN(parsed) || parsed < 0`: `setIsInvalid(true)` (store stays at last valid value)
     - Else: `setIsInvalid(false); setTip({ value: parsed, mode: 'percent' })`
   - Determine active preset: `const activePreset = !isCustom ? tip.value : null`
   - JSX layout (per UI-SPEC TipControl row layout):
     ```tsx
     <div>
       <div className="flex items-center gap-2 flex-wrap">
         <span className="text-sm font-medium w-8">Tip</span>
         {PRESETS.map((p) => (
           <Button
             key={p}
             variant={activePreset === p ? 'default' : 'outline'}
             size="sm"
             onClick={() => handlePresetClick(p)}
           >
             {p}%
           </Button>
         ))}
         <Button
           variant={isCustom ? 'default' : 'outline'}
           size="sm"
           onClick={handleCustomClick}
         >
           Custom
         </Button>
         {isCustom && (
           <div className="flex items-center gap-1">
             <Input
               value={customValue}
               onChange={handleCustomChange}
               placeholder="0"
               aria-label="Custom tip percentage"
               aria-invalid={isInvalid}
               className="w-20"
             />
             <span className="text-sm text-muted-foreground">%</span>
           </div>
         )}
         {isCustom && isInvalid && (
           <p role="alert" className="text-xs text-destructive">Enter a number</p>
         )}
         <div className="flex items-center gap-1 ml-auto">
           <Button
             variant={tip.splitMethod === 'equal' ? 'default' : 'outline'}
             size="sm"
             onClick={() => setTip({ splitMethod: 'equal' })}
           >
             Equal
           </Button>
           <Button
             variant={tip.splitMethod === 'proportional' ? 'default' : 'outline'}
             size="sm"
             onClick={() => setTip({ splitMethod: 'proportional' })}
           >
             Proportional
           </Button>
         </div>
       </div>
     </div>
     ```
