## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps inside rows (gap-1); checkbox-label gap in popover list |
| sm | 8px | Gap between form inputs and buttons (gap-2); popover row padding |
| md | 16px | Panel internal padding; gap between rows; ChargesPanel internal padding |
| lg | 24px | Gap between PeoplePanel+ItemsPanel row and ChargesPanel (gap-6) |
| xl | 32px | Page-level horizontal padding (p-8 from App shell) |
| 2xl | 48px | Not used in Phase 3 |
| 3xl | 64px | Not used in Phase 3 |

Exceptions:
- AssignmentSelector trigger button: `size="sm"` (h-7) — shorter than default (h-8) to fit inline within ItemRow without expanding row height
- Warning badge/icon on unassigned ItemRow: 16px × 16px (size-4 Lucide icon) — inline with row text, no padding exception needed
- Popover content: `p-2` (8px) with `py-1` (4px) per checkbox row — compact list, not a form
- ChargesPanel: `py-4 px-4` (16px) inner padding; renders full-width below the flex row in App.tsx

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--background`: oklch(1 0 0) = white | Page background, ChargesPanel surface, popover background |
| Secondary (30%) | `--secondary`: oklch(0.97 0 0) = near-white grey | Active/selected preset button background; popover hover row background |
| Accent (10%) | `--primary`: oklch(0.205 0 0) = near-black | Active split toggle (Equal/Proportional) fill only |
| Destructive | `--destructive`: oklch(0.577 0.245 27.325) = red | Custom input validation error border + error message text; unassigned warning icon |

Accent reserved for:
- The active split-toggle button — the currently selected Equal or Proportional button uses `variant="default"` (primary fill). The inactive button uses `variant="outline"`.
- No other elements in Phase 3.

Additional semantic values:
- `--muted-foreground`: oklch(0.556 0 0) — inactive preset button text; tax/tip label secondary text
- `--border`: oklch(0.922 0 0) — ChargesPanel border, popover border, inactive button borders
- `--input`: oklch(0.922 0 0) — custom tip/tax input field border (default state)
- `--destructive` border on custom input: replaces `--input` border when validation fails (red border, `aria-invalid="true"`)

Unassigned warning treatment:
- Icon: `AlertCircle` from lucide-react, `size-4`, `text-destructive` — inline in ItemRow between price and AssignmentSelector trigger
- No background badge — icon alone is sufficient; avoids layout disruption to ItemRow

## Interaction Contract

### AssignmentSelector (ASGN-01, ASGN-02, ASGN-03)

Trigger button:
- Variant: `variant="outline" size="sm"`
- Label states:
  - Unassigned: `"Assign ▾"` (using `<ChevronDown />` icon inline-end)
  - 1 person: `"{name} ▾"` (e.g., `"Bob ▾"`)
  - 2 people: `"{name1}, {name2} ▾"` (e.g., `"Bob, Carol ▾"`)
  - 3+ people: `"{N} people ▾"` (e.g., `"3 people ▾"`)
  - All people: `"Everyone ▾"`
- `aria-haspopup="listbox"` and `aria-expanded` reflect popover open state

Popover panel:
- Radix Popover with `align="start"` — opens below the trigger, left-aligned
- Closes on click-outside (Radix default, no override needed)
- Content: vertical list of shadcn Checkboxes, one per person
  - Each row: `flex items-center gap-2 py-1 px-2` — Checkbox + person name label
  - Checking a person adds their ID to `assignedTo`; unchecking removes it
  - Dispatches `assignItem(item.id, updatedAssignedTo)` on each checkbox change
- Separator below the person list
- "Everyone" row below separator: acts as toggle-all
  - If all people checked → clicking "Everyone" unchecks all (sets `assignedTo = []`)
  - If any person unchecked → clicking "Everyone" checks all (sets `assignedTo = [all person IDs]`)
  - Implemented as a `<Button variant="ghost" size="sm">` row, not a Checkbox

### Unassigned Warning (ASGN-04)

- Condition: `item.assignedTo.length === 0`
- Render: `<AlertCircle className="size-4 text-destructive" aria-label="Item not assigned" />` in ItemRow left section, between price text and AssignmentSelector trigger
- No tooltip needed — color + icon are sufficient
- Warning disappears immediately when at least one person is assigned (reactive to store)

### TipControl (TIP-01, TIP-02, TIP-03)

Preset buttons group:
- Four buttons: `[15%]`, `[18%]`, `[20%]`, `[Custom]`
- All: `variant="outline" size="sm"` when inactive
- Active preset: `variant="default" size="sm"` (primary fill = near-black)
- Only one preset is active at a time; selecting a new preset deactivates the current
- Selecting 15/18/20 hides the custom input (if visible); dispatches `setTip({ percent: 15|18|20, split: currentSplit })`
- "Custom" button: activates custom mode — shows the custom input inline to the right of the buttons

Custom input (visible only when Custom is active):
- `<Input>` with `placeholder="0"` and `aria-label="Custom tip percentage"`
- Appended unit label: `"%"` as static text immediately to the right of the input (`<span class="text-sm text-muted-foreground">%</span>`)
- Input width: `w-20` (80px) — narrow, numeric-only entry
- Validation: on change, parse float; if `isNaN(value) || value < 0` → `aria-invalid="true"` on input + inline error `<p class="text-xs text-destructive">Enter a number</p>` below input; store value stays at 0
- Valid input dispatches `setTip({ percent: parsedValue, split: currentSplit })`

Split toggle (always visible in TipControl):
- Two buttons: `[Equal]` `[Proportional]`
- Active: `variant="default" size="sm"`; inactive: `variant="outline" size="sm"`
- Dispatches `setTip({ percent: currentPercent, split: "equal"|"proportional" })`

### TaxControl (TAX-01, TAX-02, TAX-03)

Mode toggle:
- Two buttons: `[$]` `[%]`
- Active: `variant="default" size="sm"`; inactive: `variant="outline" size="sm"`
- `[$]` = dollar amount mode; `[%]` = percentage mode
- Switching mode clears the value input and resets store tax to 0

Value input:
- `<Input>` with `aria-label="Tax amount"` ($ mode) or `aria-label="Tax percentage"` (% mode)
- Placeholder: `"0.00"` in $ mode, `"0"` in % mode
- $ mode: unit prefix `"$"` as static text to the left of the input
- % mode: unit suffix `"%"` as static text to the right of the input
- Input width: `w-24` (96px)
- Validation: same pattern as TipControl custom input — `aria-invalid` + `<p class="text-xs text-destructive">Enter a number</p>`
- $ mode dispatches via `toCents()` then `setTax({ amountCents: cents, mode: "amount", split: currentSplit })`
- % mode dispatches `setTax({ percent: parsedFloat, mode: "percent", split: currentSplit })`

Split toggle (always visible in TaxControl):
- Two buttons: `[Equal]` `[Proportional]`
- Same pattern as TipControl split toggle

### NaN / Invalid Input Guard (D-13)

- Applies to: custom tip input, tax value input
- Guard condition: `isNaN(parseFloat(value)) || parseFloat(value) < 0`
- Effect: `aria-invalid="true"` on `<Input>` → shadcn CVA applies `border-destructive ring-destructive/20`
- Inline error message: `<p role="alert" class="text-xs text-destructive mt-1">Enter a number</p>`
- Store value: remains at 0 (last valid value) until valid number entered
- Blank input: treated as valid 0 (no error shown for empty field — user is mid-edit)

## Accessibility Contract

- All icon-only buttons carry explicit `aria-label` — required where buttons contain only SVG
- AssignmentSelector trigger: `aria-haspopup="listbox"`, `aria-expanded={isOpen}` — screen reader announces popup intent
- Unassigned warning icon: `aria-label="Item not assigned"` on `<AlertCircle>` svg — not just decorative
- Custom tip/tax inputs: `aria-invalid="true"` + `role="alert"` on error paragraph — screen reader announces error on change
- All form inputs: `aria-label` on every `<Input>` element — no inputs rely on visual proximity for label association
- Checkbox items in popover: shadcn Checkbox uses Radix `aria-checked` — accessible toggle state
- "Everyone" button in popover: `aria-label="Select everyone"` when unchecked-all, `aria-label="Deselect everyone"` when all checked
- Focus management: Radix Popover manages focus trap and restoration on open/close natively
