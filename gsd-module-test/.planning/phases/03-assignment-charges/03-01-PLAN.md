   - After person list, render a separator (`<div className="border-t my-1" />`) then an "Everyone" button: `<Button variant="ghost" size="sm" className="w-full justify-start" onClick={handleEveryoneToggle} aria-label={isAllSelected ? "Deselect everyone" : "Select everyone"}>Everyone</Button>`

   - `handleEveryoneToggle()`: if `isAllSelected` -> `assignItem(item.id, [])`, else -> `assignItem(item.id, people.map(p => p.id))`
   - Import `ChevronDown` from `lucide-react`
